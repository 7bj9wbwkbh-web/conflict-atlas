CSV → incidents.json

Converts a UCDP conflict-events file into the format Conflict Atlas reads. Runs entirely in this browser tab — nothing is uploaded anywhere, and you don't need Python or any other install. Works offline once the page is open.

1Choose your UCDP GED csv file

Drop the .csv file here, or click to browse
Download it first from ucdp.uu.se/downloads — the "GED Global" csv
×

2Filters (the defaults are sensible — change only if you want to)

Drops smaller incidents. Lower this if you want more events.
Keeps the deadliest N. Above ~2,500 the map gets heavy.

3Convert

Move the downloaded file into a folder named data next to conflict-atlas.html, so the path reads data/incidents.json. Then follow Stage 2 of the build guide to put it online.

Data: Uppsala Conflict Data Program (UCDP), ucdp.uu.se — credit them wherever you show this. This tool reads the file you choose entirely on your own computer; it is never sent anywhere.
